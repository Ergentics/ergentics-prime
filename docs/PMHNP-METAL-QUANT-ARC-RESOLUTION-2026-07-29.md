## Non-overwrite rule

The Prime typed optimizer-restore work does not replace the companion's Metal,
quantization, device, recommendation, or first-party native-language evidence.
It adds one missing prerequisite: public, typed, local-candidate Adam/AdamW
state transport and exact `N -> fresh process -> N+1` continuation.

The current CPU fixture is deliberately an API/checkpoint gate. It is not a
CPU training direction and cannot downgrade or promote an existing Metal
result. If it passes, the next execution gate is one bounded interrupted Metal
continuation canary using the same typed state contract. Most learning and
throughput work remains on maintained MLX Swift/Metal.

No historical result is rewritten:

- a prior `GROUNDED` remains grounded only for its recorded scope;
- a prior `ABSTAIN` remains an abstention until a new, separately identified
  receipt supersedes it;
- exact reload is not bitwise Metal training replay;
- a mechanics or primitive result is not functional language or product
  authority; and
- the PMHNP product route remains engine-only unless its product-truth
  contract changes explicitly.
