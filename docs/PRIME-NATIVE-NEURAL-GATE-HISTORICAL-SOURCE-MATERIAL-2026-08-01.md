## Decision

Topology V9 satisfies the bounded post-V8 prerequisite without compiling or
executing the historical gate. It adds one internal Swift library target and
no product or executable:

- `PrimeNativeNeuralGateHistoricalSourceDerivation` accepts only the exact
  native-gate and verdict-carrier byte blobs;
- it validates their frozen byte counts and SHA-256 identities before any
  line operation;
- it derives the bounded carrier declaration, the native gate's carrier-use
  site, and the exact direct historical mutation source material; and
- it returns inert in-memory bytes with every execution, detector, durability,
  verdict, receipt, science, and product authority field fixed false.

The public API does not accept a repository path, source range, expected hash,
rewrite, mutation label, failed leg, or caller-reported outcome. It performs no
filesystem, environment, Git, shell, process, Python, model, MLX, or Metal
operation.

## Fail-closed derivation

The Swift derivation requires valid UTF-8, no BOM, LF-only line endings, and a
final LF. Every line group, inserted separator, joined body, rewrite source,
transformed body, and final output is count- and SHA-bound. A rewrite source
must occur exactly once. The public V9 route uses no rewrites and permits no
caller-supplied contract values.

The production target carries a closed internal copy of only the two pins and
three derivation contracts it needs. The test target compares every field of
those copies against the PrimeCore planning contract. This keeps the planning
contract auditable without granting the production derivation target access
to PrimeCore filesystem, Git, process, publication, or model APIs.

Focused validation passed 26 tests: nine source-derivation tests and seventeen
topology tests. The environment-gated live test read the exact local pinned donor and
reproduced all three outputs twice byte-identically. BOM, CRLF, missing final
LF, invalid UTF-8, same-size source mutation, truncation, extension, every
frozen line-group mutation, non-overlapping and overlapping duplicate rewrite,
empty or duplicate rewrite identity, empty rewrite source, and invalid UTF-8
separator cases failed closed. The target-source isolation audit recursively
scans every Swift file under the target and rejects any file-set drift before
applying its forbidden-mechanics scan.
The same test performs a test-only lexical audit: the 46 ordered donor enum
declarations equal the Stage-A projection catalog, and the `mutatedReports`
switch contains every declaration exactly once. This does not add a production
Swift parser or establish an independent detector.

The donor sources remain in their first-party companion repository rather than
being duplicated as Prime test fixtures. Therefore a generic standalone
`swift test` explicitly skips the cross-repository proof when no donor root and
no requirement marker are supplied. `PRIME_REQUIRE_V9_PINNED_DONOR_GATE`
accepts only the exact value `1`; any other supplied value fails. In required
mode, a missing or empty donor root fails rather than skips. The following
command is the mandatory V9 manual pre-merge gate and must run against the exact
pinned companion checkout:

```sh
env PRIME_REQUIRE_V9_PINNED_DONOR_GATE=1 PRIME_PMHNP_COMPANION_ROOT=/path/to/pinned/pmhnp-companion-ergentics swift test --filter 'PrimeNativeNeuralGateHistoricalSourceDerivationTests|PrimeNativeNeuralGateTrapDisjointTopologyTests'
```

The full Debug root-package regression passed 581 XCTest tests with three
expected skips and an additional 12 Swift Testing tests, with zero failures.
This is process evidence, not an enforced GitHub status check: Prime currently
has no repository workflow or branch rule. Automatic enforcement requires a
later CI checkout of the private companion revision under scoped credentials.

The Release two-role actual-package secure-capture canary produced
byte-identical probe and verifier output at 48,078 bytes, SHA-256
`8c810c532f4f581a27d2db9c59305be9a19ff1b03ed69835206565008e997d1e`.
That canary validates only the existing package-description capture substrate
on the pinned host. It does not execute the donor, materialize a worker, or
