# Golden negative: polling alone
Synthetic control: a supervisor polls the exact owned PID with nonblocking wait, keeps an immutable deadline and bounded cleanup, and terminates when ownership cannot be established. The presence of a polling loop alone does not establish an indefinite-wait defect or malware. A real implementation still needs its own relevant evidence.
Known regression interpretation from the v0.1.0 Agent exercise; not a blind case or an observed live process.
