# Preserve evidence stages
A matching source hash identifies bytes. A successful build identifies a build result. Neither establishes that a loader started the program, that the intended input was consumed, or that its output is correct. Record those observations independently. A prior result stays attached to its original object and task.
This authored method note is derived from the Ergentics Agents v0.1.0 shared contract and its C/C++ role's preserved build-versus-loader lesson. It introduces no historical executable or payload.
