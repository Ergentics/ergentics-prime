## Lexical-private and discarded-evidence reality

The public historical `Assessment` does not carry the complete evidence
required by the frozen worker artifact protocol. The missing values are not a
serialization omission that a thin wrapper can repair:

- `Evaluation`, `InvariantRecordCollection`, and `MutationSweepRun` are
  lexically `private`;
- `evaluate`, `invariantRecords`, `mutationSweep`, `namedLegFails`, and
  `mutatedReports` are lexically `private`;
- the raw invariant records and their ASCII flags remain inside the private
  evaluation value;
- each `mutatedFingerprint` exists only as a local mutation-sweep intermediate
  and is discarded before public `MutationResult` construction; and
- `namedLegFails` checks the mutation's expected leg and returns one Boolean.
  The pinned gate does not compute or publish a complete observed failed-leg
  set.

Swift same-module placement permits the V11 fixture to use donor `internal`
declarations. It does not make these lexical-private declarations available to
a separate adapter file. Public summary values, including an expected leg plus
`detected == true`, cannot be expanded into records, fingerprints, or an exact
observed set.

The V12 contract therefore rejects all of the following:

- a thin wrapper around the public `Assessment`;
- reflection or unsafe-memory recovery;
- donor access-level relaxation;
- mutation of the original byte-exact gate;
- substitution of the expected-leg singleton for an observed failed-leg set;
  and
- a compact hand-reconstruction kernel that reinterprets donor semantics.

The only permitted later implementation is a full source-derived variant with
same-file instrumentation inside the derived gate's lexical scope.

## Per-mutation observed-failure domain

A complete observed failed-leg set is a fresh same-family regrade over the
nine primitive legs, in this exact order:

1. `NL1_canonical_material_reload`
2. `NL2_finite_field_sz_pool_expansion`
3. `NL3_foundation_tokenizer_corpus_regrade`
4. `NL4_raw_executor_row_regrade`
5. `NL5_causal_training_mechanics`
6. `NL6_checkpoint_durability`
7. `NL7_same_seed_initialization_training_result_replay`
8. `NL8_frozen_exact_seed_consensus`
9. `NL9_capability_and_malformed_abstention`

`NL10_mutation_synthesis` is the aggregate sweep/meta leg. It is excluded
from each mutation's primitive regrade and retained only for the aggregate
historical critical-leg values. Observed sets must follow the primitive-leg
order exactly; unknown and duplicate leg IDs are forbidden. The expected leg
must not stand in for the observed set.

The ordered allowed-failure policy is separately frozen for all 46 catalog
entries. Each allowed set is exactly the mutation's projected expected-leg
singleton; runtime widening is forbidden. The full nine-leg regrade must then
produce an independently retained observed set exactly equal to that frozen
allowed set. The singleton policy is an acceptance contract, not observation:
it may never be copied into the observed field. A mutation that causes an
additional primitive leg to fail therefore remains `ABSTAIN` rather than
silently broadening its own acceptance set.

This regrade remains same-family historical reconstruction. It is not an
independent mutation detector, a distinct implementation family, or a
four-tier AgentContractKit audit.
