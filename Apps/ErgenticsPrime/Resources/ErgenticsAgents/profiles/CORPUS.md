# Corpus, outputs and processing

This package provides a small selected corpus and local packet preparation, not a synchronization service or global memory. The seed corpus contains six authored method/control notes from this task and the versioned Agent lineage. No retained runtime, protected mathematical exam, raw conversation history, credential or model-weight file is copied.

Keep original outputs under per-run/per-profile task directories. Write only to the assigned destination and coordinate shared source edits. After relevant review, a selected lesson with attribution, exact content identity, positive control and golden negative may become a separate contribution corpus through `promote`. The qualified task-specific Auto Harvest workflow may supply candidates when applicable; this helper starts no harvesting and does not replace its checks or state.

For a receiving run, pin the corpus index and explicit entry selection. Common entries can be consumed by both profiles; profile-specific entries remain scoped. An allowlist is meaningful only against known entry metadata and the actual task authority. Do not automatically ingest every prior output. Keep known regression cases distinguishable from held-out evaluation content, and preserve independent originals before a synthesis when the comparison requires it.

A packet receipt records local file reads and material included in a prepared packet. A separate actual load observation records which files entered an Agent context. Neither alone proves a served model build, provider retention/training settings or a local-only inference path. Hosted processing of selected context remains hosted processing even when source and output files are local.

Shared workspace access is not per-Agent isolation. The helper rejects selected metadata-ineligible entries before content reads and uses one descriptor for bounded regular-file validation/reading; named ancestor checks remain best-effort and cannot prove containment against an adversary replacing directories. Use platform/OS access controls when isolation is a requirement. Do not turn these local checks into a system-wide security clearance.

Ergentics policy and source attribution govern authorized task use. A profile, corpus label, permission probe or digest does not grant independent outside reuse or establish enforcement by a provider. Bind intended recipients, purpose, storage and processing destinations in the current request. No outside transfer or training operation is part of this release.
